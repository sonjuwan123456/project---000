# 샘플 파일

넣어 보고 화면을 눈으로 볼 때 쓰는 파일들입니다. 앱에 **하나씩** 끌어다 놓으세요.
`모형/`만 폴더째(또는 zip으로 묶어서) 넣습니다 — 갈라진 glTF라 딸린 파일이 같이
가야 합니다.

이 폴더를 통째로 넣으면 `모형/`만 열립니다. 한 번에 하나를 여는 앱이고, 묶음에서
무엇을 열지 고를 때 3D 모델이 표보다 앞서기 때문입니다.

보여 주려고만 두는 것이 아니라 **읽개의 갈림길을 하나씩 밟으라고** 둔 것입니다.
갈림길 하나가 막히면 `packages/data/src/samples.test.ts`가 여기서 걸립니다.

| 파일                 | 무엇을 밟는가                                                       |
| -------------------- | ------------------------------------------------------------------- |
| `고객문의.csv`       | 범주·숫자·날짜·글자 네 갈래 컬럼, `emb_0..emb_7` 넓은 임베딩, 빈 칸 |
| `고객문의-euckr.csv` | EUC-KR로 저장된 표 — 인코딩을 가리지 못하면 글자가 통째로 깨진다    |
| `깨진.csv`           | 칸이 남는 행, 칸이 모자란 행, 닫히지 않은 따옴표                    |
| `주문.jsonl`         | 줄마다 JSON 하나, 중첩 객체를 펼쳐서 컬럼으로 만드는 길             |
| `서버.log`           | 네 레벨이 다 든 로그 — 레벨 색과 거르기                             |
| `읽어보기.md`        | 마크다운 — 제목·목록·표·코드 조각                                   |
| `예시.ts`            | 코드 — 문법 강조가 붙는 갈래                                        |
| `모형/`              | 갈라진 glTF — 파일 하나만 열면 못 찾고, 폴더째 주면 찾는다          |

`모형/`이 갈라져 있는 것이 폴더와 zip을 받는 까닭입니다. `scene.gltf` 하나만 열면
`scene.bin`과 `textures/나무 바닥.png`를 찾지 못해 안내가 뜨고, 폴더째 넣으면 그대로
그려집니다. zip으로 묶어 넣어도 같습니다.

## 다시 만들기

`고객문의*.csv`, `깨진.csv`, `주문.jsonl`, `서버.log`, `모형/`은 만들어 낸 것입니다.

```sh
cd samples && node 만들기.mjs
```

난수 씨앗이 박혀 있어 몇 번을 돌려도 같은 파일이 나옵니다. 그래서 시험이 행 수와
컬럼 갈래를 숫자로 못박을 수 있습니다. `예시.ts`와 `읽어보기.md`는 손으로 쓴 것이라
생성기가 건드리지 않습니다.

고칠 때 걸리는 자리가 하나 있습니다. **`내용` 컬럼은 평균 80자를 넘겨야 합니다.**
짧은 문장을 돌려쓰면 값이 몇 개 안 되어 `category`로 접히고, 그러면 `text` 갈래 컬럼이
하나도 없는 표가 됩니다 — 컬럼 종류 추론의 한 갈래가 빕니다
(`packages/data/src/columnType.ts`의 `categoryMaxAverageLength`).
